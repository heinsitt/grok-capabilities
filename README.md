## ✨ What is Grok?

Grok is an AI assistant built by **xAI**. It is designed to be maximally truth-seeking, helpful, and maximally curious. Grok aims to understand the universe and help humans do the same.

**Key traits:**
- Truth-seeking & maximally helpful
- Real-time knowledge + tool use
- Strong coding, reasoning, and creative abilities
- Multimodal (text, images, and more)
- Connected to tools (GitHub, web search, X/Twitter, weather, sports, and more)

## 💡 Featured Capabilities

### 1. Real-time Tool Use
Grok can search the web, look up X posts, check weather, sports, and interact with connected services like **GitHub** (create repos, push files, manage issues/PRs).

### 2. Code & Repository Wizard
Ask Grok to:
- Scaffold a new project
- Write production-ready code
- Create a polished README
- Set up GitHub Actions
- Review or fix bugs

### 3. Multimodal Creativity
- Describe an image → Grok can generate it
- Upload / describe a design → get feedback or improved versions
- Turn ideas into visual assets

### 4. Deep Reasoning
Grok is built for hard problems: math, science, philosophy, systems design, and truth-seeking conversations without political bias.
